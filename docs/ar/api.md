# 📚 توثيق الـ API Endpoints

جميع المسارات تحت `/api`، وجميع الاستجابات من هذا المسار تحمل `Cache-Control: no-store`.

## ملفات المسارات

| الملف                | المسار الأساسي   | المحتوى                     |
| -------------------- | ---------------- | --------------------------- |
| `authRoutes.js`      | `/api/auth`      | تسجيل دخول الأدمن           |
| `adminRoutes.js`     | `/api/admins`    | إدارة حسابات الأدمن         |
| `dashboardRoutes.js` | `/api/dashboard` | الإحصائيات                  |
| `storeSettingsRoutes.js` | `/api/store-settings` | رقم واتساب المتجر (`super_admin`) |
| `itemRoutes.js`      | `/api/items`     | المنتجات                    |
| `cartRoutes.js`      | `/api/carts`     | السلة                       |
| `orderRoutes.js`     | `/api/orders`    | الطلبات                     |

مسار إتمام شراء السلة (`POST /api/carts/:guestId/checkout`) موجود في `cartRoutes.js`، لكنه يستخدم `orderController`.

## 🛍️ المنتجات (Items)

| Method   | Endpoint              | الصلاحية | الوصف             |
| -------- | --------------------- | -------- | ----------------- |
| `GET`    | `/api/items`          | عام      | جلب جميع المنتجات |
| `POST`   | `/api/items`          | `admin+` | إضافة منتج جديد   |
| `PUT`    | `/api/items/:id`      | `admin+` | تعديل منتج        |
| `DELETE` | `/api/items/:id`      | `admin+` | حذف منتج          |

> `admin+` تعني: `admin` أو `moderator` أو `super_admin`. وبنفس الطريقة `moderator+` تعني: `moderator` أو `super_admin`.

### قواعد الإضافة والتعديل (`POST` و`PUT`)

| الحقل          | القاعدة                                                     |
| -------------- | ----------------------------------------------------------- |
| `itemName`     | مطلوب، بحد أقصى **100** حرف                                 |
| `itemPrice`    | رقم من `0` إلى **1,000,000**                                |
| `itemQuantity` | عدد صحيح من `0` إلى **100,000**                             |
| `images`       | من **1 إلى 6** صور؛ كل `imageURL` يجب أن يكون `http`/`https` وبحد أقصى **500** حرف |

الحدود موجودة في `ITEM_LIMITS` داخل `src/utils/constants.js`.

## 🔐 الأدمن (Admins)

| Method  | Endpoint                       | الصلاحية      | الوصف                                                         |
| ------- | ------------------------------ | ------------- | ------------------------------------------------------------- |
| `POST`  | `/api/admins`                  | `super_admin` | إنشاء حساب أدمن جديد                                          |
| `GET`   | `/api/admins`                  | `super_admin` | جلب جميع الأدمنز بدون كلمات المرور (`404` إذا لا توجد بيانات) |
| `PATCH` | `/api/admins/:adminId/disable` | `super_admin` | تعطيل حساب أدمن                                               |
| `PATCH` | `/api/admins/:adminId/enable`  | `super_admin` | تفعيل حساب أدمن                                               |

### قواعد تعطيل الحسابات

- لا يمكن للأدمن تعطيل حسابه بنفسه (`400`).
- لا يمكن تعطيل آخر حساب `super_admin` نشط (`400`)، حتى لا يبقى النظام بدون مدير عام.
- أي حساب غير موجود يرجع `404`.

## 🛒 السلة (Cart)

يعتمد نظام السلة على `guestId` من نوع **UUID v4**، ويتم تخزينه في متصفح المستخدم للتعرف على سلته بدون الحاجة إلى تسجيل الدخول.

يتم إرسال `guestId` ضمن مسار الطلب، ويتم التحقق منه قبل معالجة العملية، بالإضافة إلى التحقق من معرّفات المنتجات `:id` عند الحاجة.

| Method   | Endpoint                                   | الوصف                    |
| -------- | ------------------------------------------ | ------------------------ |
| `GET`    | `/api/carts/:guestId`                      | جلب محتويات السلة        |
| `POST`   | `/api/carts/:guestId/items`                | إضافة منتج إلى السلة     |
| `PATCH`  | `/api/carts/:guestId/items/:id/increase`   | زيادة كمية منتج في السلة |
| `PATCH`  | `/api/carts/:guestId/items/:id/decrease`   | تقليل كمية منتج في السلة |
| `DELETE` | `/api/carts/:guestId/items/:id`            | حذف منتج واحد من السلة   |
| `DELETE` | `/api/carts/:guestId/items`                | تفريغ السلة بالكامل      |

## 📦 الطلبات (Orders)

| Method  | Endpoint                                | الصلاحية     | الوصف                                    |
| ------- | --------------------------------------- | ------------ | ---------------------------------------- |
| `POST`  | `/api/orders`                           | عام          | شراء مباشر لمنتج واحد بدون المرور بالسلة |
| `POST`  | `/api/carts/:guestId/checkout`          | عام          | إتمام شراء جميع محتويات السلة            |
| `GET`   | `/api/orders`                           | `moderator+` | جلب جميع الطلبات من لوحة التحكم          |
| `PATCH` | `/api/orders/:orderId`                  | `moderator+` | تعديل حالة الطلب (Body: `{ "status" }`)  |
| `POST`  | `/api/orders/track`                     | عام          | البحث عن طلب واحد برمز التأكيد + رقم الهاتف (Body: `{ "code", "phoneNumber" }`) |
| `POST`  | `/api/orders/track-many`                | عام          | بيانات جديدة لحتى 20 طلب مرة واحدة (Body: `{ "orders": [{ "code", "phoneNumber" }] }`) |
| `POST`  | `/api/orders/cancel`                    | عام          | الزبون يلغي طلباً `Pending` بالرمز + الرقم (Body: `{ "code", "phoneNumber" }`). المخزون يرجع |
| `POST`  | `/api/orders/confirm`                   | `moderator+` | تأكيد الطلب يدوياً (Body: `{ "code", "senderPhone" }`) |
| `GET`   | `/api/orders/:id/confirmation`          | `bot`        | حالة تأكيد واتساب. 🚧 **موجود فقط عندما `WHATSAPP_BOT_ENABLED=true`** (غير ذلك `404`) |

### بيانات الشراء (Body)

الشراء المباشر (`POST /api/orders`):

```json
{
  "itemId": "6a780926966bdf371b4d67bf",
  "quantity": 2,
  "purchaseDetails": {
    "fullName": "اسم العميل",
    "countryCode": "+970",
    "phoneNumber": "599123456",
    "region": "hebron"
  }
}
```

إتمام شراء السلة (`POST /api/carts/:guestId/checkout`) يرسل `purchaseDetails` فقط، وبعد النجاح يتم تفريغ السلة.

قواعد `purchaseDetails`:

- `fullName` و`region` مطلوبان، ويتم حذف محارف Unicode الخفية منهما.
- `phoneNumber`: يتم حذف المسافات و `-` و `( )` و `.` و **صفر واحد في البداية**، ثم يجب أن يكون **9 أرقام** بالضبط (`0599 123-456` ← `599123456`). التنظيف موجود في `src/utils/phone.js`.
- `countryCode`: `+970` أو `+972`.
- `region`: إحدى القيم في `REGIONS` (`src/utils/constants.js`)، مثل `hebron` و`dura` و`yatta`.
- `quantity` (الشراء المباشر): عدد صحيح أكبر من `0`.

### حالات الطلب

```text
Pending
Accepted
Delivered
Cancelled
```

### أمثلة على استجابات الشراء المباشر

| الحالة                                  | الكود |
| --------------------------------------- | ----- |
| نجاح الشراء (يحتوي `data.orderId` و`data.updatedItem`) | `201` |
| بيانات غير صالحة (معرّف أو كمية)        | `400` |
| الكمية المطلوبة أكبر من المخزون         | `400` |
| المنتج غير موجود أو محذوف               | `404` |
| لا يوجد رقم واتساب للمتجر               | `503` |

# 🔑 نظام الصلاحيات (Roles)

يحتوي النظام على **3 مستويات من الصلاحيات**، ويتم حماية كل endpoint إداري حسب الصلاحية المطلوبة.

| الرتبة        | الصلاحيات                                                                              |
| ------------- | -------------------------------------------------------------------------------------- |
| `admin`       | إضافة، تعديل وحذف المنتجات                                                             |
| `moderator`   | جميع صلاحيات `admin` بالإضافة إلى إدارة الطلبات                                        |
| `super_admin` | جميع الصلاحيات بالإضافة إلى إدارة حسابات الأدمن (إنشاء، تفعيل، تعطيل) والوصول للإحصائيات |

### مصادقة الأدمن

تتم المصادقة باستخدام **JWT Bearer Token**:

```http
Authorization: Bearer <token>
```

- التوكن صالح لمدة **48 ساعة**، ويحتوي على `id` و`role` الخاصين بالأدمن.
- الحساب المعطّل لا يستطيع تسجيل الدخول (`403`).
- الحساب المعطّل (`isActive: false`) يتم رفض طلباته أيضاً بـ `401` حتى لو كان التوكن الخاص به لا يزال صالحاً.
- كل طلب ناجح للأدمن يحدّث `lastActivityAt` الخاص به.
- بدون توكن أو بصلاحية غير مناسبة ← `401` / `403`.

# 🏪 إعدادات المتجر (Store Settings)

فقط `super_admin` يستطيع رؤيتها أو تغييرها (ما عدا `/public`). تستخدمها صفحة الـ Frontend `/admin/store-settings`.

| الطريقة | المسار                | الصلاحية      | الوصف                                            |
| ------- | --------------------- | ------------- | ------------------------------------------------ |
| `GET`   | `/api/store-settings` | `super_admin` | رقم واتساب المتجر، ومتى ومن غيّره                |
| `GET`   | `/api/store-settings/public` | عام    | رقم واتساب المتجر **فقط** (`{ "whatsappNumber" }` أو `null`). يستخدمه قسم "تواصل مع الدعم" في "طلباتي" |
| `PUT`   | `/api/store-settings` | `super_admin` | حفظ رقم واتساب المتجر (Body: `{ "whatsappNumber" }`) |

رد `GET` (`whatsappNumber` يكون `null` إذا لا يوجد رقم محفوظ):

```json
{
  "success": true,
  "data": {
    "whatsappNumber": "+970599123456",
    "updatedAt": "2026-11-26T12:00:00.000Z",
    "updatedBy": "Super Admin"
  }
}
```

- `PUT` ينظّف الرقم بـ `normalizePhone` (`"+970 0599-123-456"` ← `"+970599123456"`). الرقم الخاطئ ← `400` `INVALID_PHONE`، والرقم القديم يبقى.
- يحفظ `updatedBy` (الأدمن الذي غيّره). يوجد دائماً مستند إعدادات **واحد** (`key: "main"`، upsert).
- يمكن **تغيير** الرقم لكن **لا يمكن حذفه**: بدون رقم، كل عمليات الشراء تتوقف (`503`).
- `/public` لا يعرض أي شيء آخر (لا تواريخ ولا اسم الأدمن). الرقم ليس سرياً: الزبائن يرونه أصلاً في رابط واتساب بعد الشراء.
- حد الطلبات: 100 لـ `GET`، و300 لـ `GET /public`، و20 لـ `PUT`.
- السكربت [`storeSettingsSeed.js`](scripts.md#-رقم-واتساب-المتجر-storesettingsseedjs) ما زال يعمل (للإعداد الأول، قبل دخول أي `super_admin`).

# 📊 الإحصائيات (Analytics)

الإحصائيات متاحة فقط لـ `super_admin`.

| Method | Endpoint                   | الصلاحية      | الوصف               |
| ------ | -------------------------- | ------------- | ------------------- |
| `GET`  | `/api/dashboard/analytics` | `super_admin` | إحصائيات آخر 7 أيام |

الاستجابة (`data`) تحتوي على:

| الحقل            | المعنى                                                  | الفترة         |
| ---------------- | ------------------------------------------------------- | -------------- |
| `totalRevenue`   | 💰 مجموع `totalPrice`                                    | آخر 7 أيام     |
| `totalOrders`    | عدد الطلبات                                             | آخر 7 أيام     |
| `ordersByStatus` | 📦 عدد الطلبات لكل حالة (`Pending`، `Accepted`...)       | آخر 7 أيام     |
| `topProduct`     | 🏆 أكثر منتج مبيعاً (حسب الكمية)                         | آخر 7 أيام     |
| `topRegions`     | 📍 أكثر 5 مناطق حسب عدد الطلبات                          | آخر 7 أيام     |
| `totalItems`     | عدد المنتجات                                            | كل الوقت       |
| `activeCarts`    | عدد السلال في قاعدة البيانات                            | كل الوقت       |
| `lowStockItems`  | ⚠️ المنتجات التي كميتها **5 أو أقل**                     | الآن           |
